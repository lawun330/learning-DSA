# DSA Learning
A comprehensive collection of **Data Structures and Algorithms** implementations demonstrating fundamental computer science concepts. This repository contains various implementations with detailed comments and documentation, perfect for learning and reference.

## Project Structure

### 📊 Data Structures (`Data_Structures/src/`)
- **📚 Stack**
  - Array-based implementations (Generic and Simple)
  - Linked implementations
- **🌳 Trees**
  - **🔍 Binary Search Tree (BST)**
    - Array-based implementations (Fixed and Dynamic)
    - Linked implementation
  - **⚖️ AVL Tree** (self-balanced BST)

Multiple implementation approaches demonstrate different techniques:
- **📋 Array-based**: Fixed-size and dynamic array implementations
- **🔗 Linked**: Node-based pointer implementations
- **🔧 Generic vs Simple**: Full ADT pattern vs simplified versions

***

### ⚡ Algorithms (`Algorithms/src/`)
- **🔄 Sorting Algorithms**
  - `InsertionSort.java` - Simple insertion sort implementation
  - `QuickSort.java` - Divide-and-conquer quick sort with pivot selection
  - `ShellSort.java` - Shell sort with gap sequence optimization
  - `MergeSort.java` - Standard and Jeliot versions of merge sort
- **🕸️ Graph Algorithms**
  - `PrimAlgorithm.java` - Prim's algorithm for Minimum Spanning Tree (vertex-based, O(E log V))
  - `KruskalAlgorithm.java` - Kruskal's algorithm for Minimum Spanning Tree (edge-based, O(E log E))
- **🧠 Dynamic Programming**
  - `Knapsack.java` - 0/1 Knapsack problem solution with DP and backtracking
- **🎯 Optimization**
  - `SimplexMethod.java` - Linear programming solver using simplex method
- **🔧 Others**
  - `BufferPool.java` - Buffer pool implementation for efficient memory management
  - `BinarySearch.java` - Binary search algorithm for finding elements in sorted arrays
